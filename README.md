# Young Gentleman — Premium Kids Wear

This is a lightweight static buyer-preview website for the first phase of Young Gentleman. It uses the supplied logo, garment-tag reference and sample design images.

## What is included
- Premium editorial-style homepage
- Responsive mobile navigation
- Collection grid with 18 sample styles
- Polos / T-Shirts / Statement filters
- Quick-view product modal
- Lookbook
- Brand story and signature garment-tag section
- Buyer / wholesale section with the ₹500–₹1,000 and ₹1,000–₹2,000 positioning
- Enquiry form that prepares an email
- No cart/payment system — intentionally kept simple for Phase 1
- `.nojekyll` for simple GitHub Pages publishing

## One thing to change before publishing
Open `script.js` and replace:
`REPLACE_WITH_YOUR_YOUNG_GENTLEMAN_EMAIL`
with the actual business email you want buyers to use.

## GitHub Pages
GitHub Pages can publish static files directly from a repository. The site entry file must be a top-level `index.html`.

1. Create a new public GitHub repository.
2. Upload everything inside this folder to the repository root.
3. Go to **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Choose branch `main` and folder `/ (root)`.
6. Save and wait for the Pages deployment.
7. Your URL will normally look like `https://YOUR-USERNAME.github.io/REPOSITORY-NAME/`.

Official GitHub instructions:
https://docs.github.com/en/pages/getting-started-with-github-pages/creating-a-github-pages-site
